## Production Guidelines

### Video Specifications
- **Format**: MP4 (H.264)
- **Resolution**: 1080p (1920x1080)
- **Frame Rate**: 30 fps
- **Audio**: Hindi narration, clear and slow
- **Subtitles**: Marathi (SRT format)
- **Duration**: 3-5 minutes per video
- **File Size**: <50MB per video

### Recording Setup
- **Screen Recording**: Use Android emulator or real device
- **Audio**: Clear Hindi narration with minimal background noise
- **Lighting**: Bright, clear screen visibility
- **Pace**: Slow and clear for low-literacy users

### Accessibility
- Large text overlays for key points
- Visual indicators (arrows, highlights)
- Pause at important steps
- Repeat critical actions

### Distribution
- Host on YouTube (unlisted)
- Embed in app
- Available for offline download
- CDN delivery for fast loading
