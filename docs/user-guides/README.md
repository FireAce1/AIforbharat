## Accessing Documentation

### In-App Help
All documentation is accessible within the KrishiAI mobile app:
1. Open the app
2. Tap the menu icon (☰)
3. Select "Help & Support" / "मदद और सहायता" / "मदत आणि समर्थन"
4. Choose your preferred language

### Website
Visit https://krishiai.app/help for web-based documentation

### Offline Access
All guides are cached in the app for offline viewing
