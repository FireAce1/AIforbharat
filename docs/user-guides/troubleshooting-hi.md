# KrishiAI समस्या निवारण गाइड

## सामान्य समस्याएं और समाधान

### 📱 ऐप इंस्टॉलेशन समस्याएं

#### समस्या 1: ऐप Play Store पर नहीं मिल रहा है
**कारण**: क्षेत्र प्रतिबंध या पुराना Android संस्करण

**समाधान**:
1. सुनिश्चित करें कि आपका Android संस्करण 8.0 या उससे ऊपर है
   - सेटिंग्स → About Phone → Android Version
2. Play Store ऐप अपडेट करें
3. APK फाइल से डाउनलोड करें: https://krishiai.app/download

#### समस्या 2: "App not installed" त्रुटि
**कारण**: अपर्याप्त स्टोरेज या सुरक्षा सेटिंग्स

**समाधान**:
1. स्टोरेज जांचें: सेटिंग्स → Storage (कम से कम 100MB खाली होना चाहिए)
2. पुराने ऐप्स या फोटो हटाएं
3. "Unknown sources से इंस्टॉल करें" सक्षम करें:
   - सेटिंग्स → Security → Unknown Sources → Enable
4. फोन रीस्टार्ट करें और फिर से कोशिश करें

#### समस्या 3: इंस्टॉलेशन के दौरान ऐप अटक जाता है
**समाधान**:
1. Play Store कैश साफ करें:
   - सेटिंग्स → Apps → Play Store → Storage → Clear Cache
2. Play Store डेटा साफ करें (यदि कैश काम नहीं करता)
3. फोन रीस्टार्ट करें
4. WiFi से कनेक्ट करें (तेज डाउनलोड के लिए)

### 🔐 रजिस्ट्रेशन और लॉगिन समस्याएं

#### समस्या 4: OTP नहीं आ रहा है
**कारण**: नेटवर्क समस्या, गलत नंबर, या SMS सेवा विफलता

**समाधान**:
1. **नेटवर्क जांचें**:
   - सुनिश्चित करें कि आपके पास मोबाइल सिग्नल है
   - Airplane mode बंद करें
   - WiFi बंद करें और मोबाइल डेटा चालू करें

2. **नंबर सत्यापित करें**:
   - सुनिश्चित करें कि नंबर सही है
   - +91 के साथ 10 अंक होने चाहिए

3. **30 सेकंड प्रतीक्षा करें**:
   - "फिर से भेजें" बटन पर टैप करें

4. **SMS इनबॉक्स जांचें**:
   - कभी-कभी OTP spam फोल्डर में जाता है

5. **यदि अभी भी नहीं आता**:
   - फोन रीस्टार्ट करें
   - 5 मिनट प्रतीक्षा करें और फिर से कोशिश करें
   - support@krishiai.app पर संपर्क करें

#### समस्या 5: "Invalid OTP" त्रुटि
**कारण**: गलत OTP, समाप्त OTP, या पहले से उपयोग किया गया OTP

**समाधान**:
1. OTP सावधानी से फिर से दर्ज करें
2. सुनिश्चित करें कि OTP 5 मिनट के भीतर है
3. नया OTP मांगें: "फिर से भेजें" पर टैप करें
4. सुनिश्चित करें कि आप नवीनतम OTP का उपयोग कर रहे हैं

#### समस्या 6: "Too many OTP requests" त्रुटि
**कारण**: 1 घंटे में 5 से अधिक OTP अनुरोध

**समाधान**:
1. 1 घंटा प्रतीक्षा करें
2. यदि तत्काल पहुंच की आवश्यकता है, तो support@krishiai.app पर संपर्क करें
3. अपना मोबाइल नंबर और समस्या का विवरण प्रदान करें

### 📸 रोग पहचान समस्याएं

#### समस्या 7: कैमरा नहीं खुल रहा है
**कारण**: Permission नहीं दी गई या कैमरा किसी अन्य ऐप द्वारा उपयोग में है

**समाधान**:
1. **Camera permission दें**:
   - सेटिंग्स → Apps → KrishiAI → Permissions → Camera → Allow
2. **अन्य ऐप्स बंद करें**:
   - हाल के ऐप्स बटन दबाएं
   - सभी ऐप्स बंद करें
3. **फोन रीस्टार्ट करें**
4. **कैमरा ऐप परीक्षण करें**:
   - डिफ़ॉल्ट कैमरा ऐप खोलें
   - यदि यह काम नहीं करता है, तो हार्डवेयर समस्या हो सकती है

#### समस्या 8: तस्वीर धुंधली आ रही है
**कारण**: कैमरा फोकस, कम रोशनी, या हाथ हिलना

**समाधान**:
1. **अच्छी रोशनी में तस्वीर लें**:
   - दिन के उजाले में बाहर जाएं
   - फ्लैश का उपयोग करें (यदि आवश्यक हो)

2. **कैमरा फोकस करें**:
   - पत्ती पर टैप करें फोकस करने के लिए
   - 2-3 सेकंड प्रतीक्षा करें

3. **स्थिर रखें**:
   - दोनों हाथों से फोन पकड़ें
   - कोहनी को शरीर पर टिकाएं

4. **सही दूरी**:
   - पत्ती से 20-30 सेमी दूर रहें

#### समस्या 9: "No disease detected" या कम विश्वास स्कोर
**कारण**: खराब तस्वीर गुणवत्ता या असमर्थित फसल/रोग

**समाधान**:
1. **बेहतर तस्वीर लें**:
   - प्रभावित हिस्से को स्पष्ट रूप से दिखाएं
   - पूरी पत्ती फ्रेम में होनी चाहिए
   - पृष्ठभूमि साफ रखें

2. **एक समय में एक पत्ती**:
   - कई पत्तियों की तस्वीर न लें

3. **समर्थित फसलें जांचें**:
   - 38 प्रमुख फसलें समर्थित हैं
   - FAQ में पूरी सूची देखें

4. **यदि अभी भी समस्या है**:
   - तस्वीर support@krishiai.app पर भेजें
   - हम मैन्युअल रूप से जांच करेंगे

#### समस्या 10: रोग पहचान धीमी है (>5 सेकंड)
**कारण**: कम RAM, पुराना फोन, या बहुत सारे ऐप्स चल रहे हैं

**समाधान**:
1. **अन्य ऐप्स बंद करें**:
   - हाल के ऐप्स बटन → सभी बंद करें

2. **फोन रीस्टार्ट करें**

3. **स्टोरेज साफ करें**:
   - सेटिंग्स → Storage → Free up space

4. **ऐप कैश साफ करें**:
   - सेटिंग्स → Apps → KrishiAI → Storage → Clear Cache

### 🌾 फसल सिफारिश समस्याएं

#### समस्या 11: "Unable to fetch recommendations" त्रुटि
**कारण**: इंटरनेट कनेक्शन या सर्वर समस्या

**समाधान**:
1. **इंटरनेट जांचें**:
   - WiFi या मोबाइल डेटा चालू करें
   - ब्राउज़र में कोई वेबसाइट खोलें

2. **फिर से कोशिश करें**:
   - "सिफारिश प्राप्त करें" पर फिर से टैप करें

3. **कैश्ड सिफारिशें देखें**:
   - यदि आपने पहले सिफारिश प्राप्त की है, तो वह दिखाई देगी

4. **बाद में कोशिश करें**:
   - सर्वर रखरखाव हो सकता है

#### समस्या 12: सिफारिशें मेरे क्षेत्र के लिए उपयुक्त नहीं लगतीं
**कारण**: गलत खेत जानकारी या पुराना डेटा

**समाधान**:
1. **खेत प्रोफाइल जांचें**:
   - सेटिंग्स → खेत प्रबंधन
   - स्थान, मिट्टी का प्रकार, सिंचाई सत्यापित करें

2. **स्थान अपडेट करें**:
   - यदि आप दूसरे खेत में हैं, तो स्थान अपडेट करें

3. **नई सिफारिश प्राप्त करें**:
   - अपडेट के बाद फिर से "सिफारिश प्राप्त करें" पर टैप करें

4. **स्थानीय विशेषज्ञ से परामर्श करें**:
   - AI सिफारिशें सामान्य हैं
   - स्थानीय स्थितियों के लिए विशेषज्ञ से पूछें

### 💰 बाजार भाव समस्याएं

#### समस्या 13: "No prices available" संदेश
**कारण**: आपके क्षेत्र में कोई मंडी नहीं या डेटा अपडेट नहीं हुआ

**समाधान**:
1. **स्थान जांचें**:
   - सुनिश्चित करें कि GPS सही स्थान दिखा रहा है

2. **50 किमी के भीतर मंडी**:
   - हम 50 किमी के भीतर मंडियां दिखाते हैं
   - यदि कोई नहीं है, तो संदेश दिखाई देगा

3. **बाद में कोशिश करें**:
   - भाव सुबह 6:00 बजे अपडेट होते हैं

4. **इंटरनेट कनेक्शन**:
   - ताजा डेटा के लिए इंटरनेट की आवश्यकता है

#### समस्या 14: मूल्य अलर्ट SMS नहीं आ रहा है
**कारण**: गलत नंबर, SMS सेवा समस्या, या लक्ष्य मूल्य नहीं पहुंचा

**समाधान**:
1. **अलर्ट सेटिंग्स जांचें**:
   - बाजार भाव → अलर्ट → सक्रिय अलर्ट देखें

2. **मोबाइल नंबर सत्यापित करें**:
   - सेटिंग्स → प्रोफाइल → नंबर जांचें

3. **लक्ष्य मूल्य यथार्थवादी रखें**:
   - वर्तमान मूल्य के करीब लक्ष्य सेट करें

4. **धैर्य रखें**:
   - अलर्ट तभी आएगा जब मूल्य लक्ष्य तक पहुंचेगा

### 🌦️ मौसम और पानी समस्याएं

#### समस्या 15: मौसम डेटा पुराना दिख रहा है
**कारण**: इंटरनेट कनेक्शन या कैश्ड डेटा

**समाधान**:
1. **इंटरनेट कनेक्ट करें**:
   - मौसम हर 6 घंटे अपडेट होता है

2. **मैन्युअल रिफ्रेश**:
   - स्क्रीन नीचे खींचें (Pull to refresh)

3. **"अंतिम अपडेट" समय जांचें**:
   - यदि 6 घंटे से अधिक पुराना है, तो सिंक करें

4. **ऑफलाइन मोड**:
   - ऑफलाइन में, 7 दिन का कैश्ड डेटा दिखाया जाता है

#### समस्या 16: पानी सलाह समझ नहीं आ रही है
**समाधान**:
1. **"ℹ️" आइकन पर टैप करें**:
   - विस्तृत व्याख्या मिलेगी

2. **मुख्य बिंदु**:
   - "सिंचाई करें" = हां/नहीं
   - "पानी की मात्रा" = कितना (mm)
   - "समय" = कब (सुबह/शाम)
   - "बचाया गया पानी" = पारंपरिक विधि की तुलना में

3. **वीडियो ट्यूटोरियल देखें**:
   - मेनू → मदद → वीडियो → "पानी सलाह"

4. **गांव समन्वयक से पूछें**

### 📋 सरकारी योजना समस्याएं

#### समस्या 17: कोई योजना नहीं दिख रही है
**कारण**: फ़िल्टर सेटिंग्स या कोई पात्र योजना नहीं

**समाधान**:
1. **फ़िल्टर हटाएं**:
   - "सभी योजनाएं" चुनें

2. **खेत प्रोफाइल जांचें**:
   - पात्रता आपकी जमीन, फसल, स्थान पर निर्भर करती है

3. **इंटरनेट कनेक्ट करें**:
   - योजना डेटा साप्ताहिक अपडेट होता है

4. **बाद में जांचें**:
   - नई योजनाएं नियमित रूप से जोड़ी जाती हैं

#### समस्या 18: आवेदन लिंक नहीं खुल रहा है
**कारण**: ब्राउज़र समस्या या गलत URL

**समाधान**:
1. **डिफ़ॉल्ट ब्राउज़र सेट करें**:
   - सेटिंग्स → Apps → Default Apps → Browser

2. **URL कॉपी करें**:
   - लिंक को लंबे समय तक दबाएं → Copy
   - Chrome या अन्य ब्राउज़र में पेस्ट करें

3. **बाद में कोशिश करें**:
   - सरकारी वेबसाइट डाउन हो सकती है

### ⚙️ सामान्य तकनीकी समस्याएं

#### समस्या 23: ऐप धीमा है या लैग कर रहा है
**कारण**: कम RAM, बहुत सारे ऐप्स, या कैश

**समाधान**:
1. **अन्य ऐप्स बंद करें**:
   - हाल के ऐप्स → सभी बंद करें

2. **कैश साफ करें**:
   - सेटिंग्स → Apps → KrishiAI → Storage → Clear Cache

3. **फोन रीस्टार्ट करें**

4. **स्टोरेज साफ करें**:
   - पुरानी फोटो, वीडियो हटाएं

5. **ऐप अपडेट करें**:
   - Play Store → KrishiAI → Update

#### समस्या 24: ऐप क्रैश हो रहा है
**कारण**: बग, कम मेमोरी, या पुराना संस्करण

**समाधान**:
1. **ऐप बंद करें और फिर से खोलें**

2. **फोन रीस्टार्ट करें**

3. **ऐप अपडेट करें**:
   - Play Store → KrishiAI → Update

4. **ऐप डेटा साफ करें** (अंतिम उपाय):
   - सेटिंग्स → Apps → KrishiAI → Storage → Clear Data
   - ⚠️ चेतावनी: यह सभी स्थानीय डेटा हटा देगा

5. **लॉग भेजें**:
   - मेनू → सेटिंग्स → "क्रैश रिपोर्ट भेजें"
   - या support@krishiai.app पर ईमेल करें

#### समस्या 25: "App not responding" संदेश
**समाधान**:
1. **"Wait" चुनें**:
   - कुछ सेकंड प्रतीक्षा करें

2. **यदि बार-बार होता है**:
   - ऐप बंद करें → फोन रीस्टार्ट करें

3. **ऐप पुनः इंस्टॉल करें**:
   - Uninstall → फिर से Install

### 🔋 बैटरी और डेटा समस्याएं

#### समस्या 26: ऐप बहुत अधिक बैटरी उपयोग कर रहा है
**समाधान**:
1. **बैकग्राउंड सिंक बंद करें**:
   - सेटिंग्स → सिंक → "केवल WiFi पर सिंक करें"

2. **स्थान सेवाएं अनुकूलित करें**:
   - सेटिंग्स → Location → "Battery Saving" मोड

3. **अनावश्यक सुविधाएं बंद करें**:
   - पुश नोटिफिकेशन कम करें

#### समस्या 27: ऐप बहुत अधिक डेटा उपयोग कर रहा है
**समाधान**:
1. **केवल WiFi पर सिंक करें**:
   - सेटिंग्स → सिंक → "केवल WiFi पर सिंक करें"

2. **छवि गुणवत्ता कम करें**:
   - सेटिंग्स → डेटा उपयोग → "कम गुणवत्ता छवियां"

3. **डेटा उपयोग जांचें**:
   - सेटिंग्स → डेटा उपयोग → विवरण देखें
