# WhatsApp Support Channel Guide

## Overview

WhatsApp is the primary support channel for KrishiAI farmers and village coordinators. This guide outlines the setup, management, and best practices for WhatsApp support.

## Support Structure

### Support Groups

#### 1. Farmer Support Group (Main)
- **Purpose**: Direct farmer support and queries
- **Members**: Farmers, village coordinators, support team
- **Language**: Hindi, Marathi
- **Response Time**: 2 hours during business hours

#### 2. Village Coordinator Group
- **Purpose**: Coordinator training and escalations
- **Members**: Village coordinators, support team, product team
- **Language**: Hindi, Marathi, English
- **Response Time**: 1 hour during business hours

#### 3. Technical Support Group (Internal)
- **Purpose**: Technical issues and bug reports
- **Members**: Support team, engineering team
- **Language**: English
- **Response Time**: 30 minutes

### 3. Quick Reply Templates

#### Common Issues

**App Not Opening**
```
ऐप नहीं खुल रहा है? कृपया ये कदम आजमाएं:

1️⃣ फोन को रीस्टार्ट करें
2️⃣ ऐप को अपडेट करें (Play Store)
3️⃣ इंटरनेट कनेक्शन चेक करें
4️⃣ ऐप को अनइंस्टॉल और फिर इंस्टॉल करें

```

**Login Issues**
```
लॉगिन में समस्या? कृपया ये जांचें:

1️⃣ फोन नंबर सही है?
2️⃣ OTP 5 मिनट में एक्सपायर हो जाता है
3️⃣ "Resend OTP" पर क्लिक करें
4️⃣ नेटवर्क कनेक्शन चेक करें

OTP नहीं आ रहा? हमें अपना नंबर भेजें।
```

**Disease Detection Not Working**
```
रोग पहचान में समस्या? कृपया ये सुनिश्चित करें:

2️⃣ फोटो साफ और फोकस में है?
3️⃣ पत्ती/पौधे का पूरा हिस्सा दिख रहा है?
4️⃣ अच्छी रोशनी में फोटो लें

फिर भी समस्या? फोटो हमें भेजें।

**Offline Mode**
```
ऑफलाइन मोड के बारे में:

✅ रोग पहचान - ऑफलाइन काम करता है

1️⃣ होम स्क्रीन पर "बाजार भाव" पर क्लिक करें
2️⃣ अपनी फसल चुनें
3️⃣ नजदीकी मंडियों के भाव देखें
4️⃣ 7/30/90 दिन का पूर्वानुमान देखें

भाव रोज सुबह 6 बजे अपडेट होते हैं।

## Support Workflow

### 1. Message Triage (Within 15 minutes)

```
Priority Levels:
P0 - Critical: Cannot use app, data loss
P1 - High: Major feature not working
P2 - Medium: Minor feature issue
P3 - Low: Questions, feature requests
```

### 2. Response Guidelines

#### First Response (Within 2 hours)
- Acknowledge the message
- Ask clarifying questions if needed
- Provide initial troubleshooting steps
- Set expectations for resolution time

#### Follow-up (As needed)
- Update on progress
- Request additional information
- Provide workarounds
- Confirm resolution

### 3. Escalation Process

```
Level 1: Support Team (WhatsApp)
  ↓ (If unresolved in 4 hours)
Level 2: Technical Support Group
  ↓ (If unresolved in 24 hours)
Level 3: Engineering Team
  ↓ (If critical)
Level 4: Product Manager
```

## Common Scenarios

### Scenario 1: Farmer Cannot Login

**Farmer Message**: "OTP नहीं आ रहा है"

**Response**:
```
नमस्ते! मैं आपकी मदद करता हूं।

कृपया ये बताएं:
1. आपका फोन नंबर क्या है?
2. कितनी देर से OTP का इंतजार कर रहे हैं?
3. क्या आपको कोई error message दिख रहा है?

इस बीच, कृपया:
- नेटवर्क सिग्नल चेक करें
- SMS inbox चेक करें (spam folder भी)
- 30 सेकंड बाद "Resend OTP" try करें
```

### Scenario 2: Disease Detection Giving Wrong Results

**Farmer Message**: "रोग पहचान गलत बता रहा है"

**Response**:
```
धन्यवाद! हम इसे सुधारने में मदद करेंगे।

कृपया ये भेजें:
1. पौधे की फोटो (साफ और फोकस में)
2. कौन सी फसल है?
3. ऐप ने क्या बताया?
4. असली रोग क्या है? (अगर पता है)

हम इसे हमारी टीम को भेजेंगे और ऐप को बेहतर बनाएंगे।
```

### Scenario 3: App Crashing

**Farmer Message**: "ऐप बार-बार बंद हो जाता है"

**Response**:
```
समस्या के लिए खेद है। कृपया ये जानकारी दें:

1. फोन का मॉडल?
2. Android version?
3. कब crash होता है? (कौन सी screen पर?)
4. क्या error message दिखता है?

तुरंत मदद के लिए:
- फोन restart करें
- ऐप update करें (Play Store)
- अगर 2GB से कम RAM है, तो दूसरे ऐप बंद करें

हम इसे तुरंत देखेंगे।
```

## Best Practices

### Do's ✅
- Respond in the user's language (Hindi/Marathi)
- Use simple, clear language
- Provide step-by-step instructions
- Use emojis for better readability
- Follow up until issue is resolved
- Thank users for their patience
- Collect feedback

### Don'ts ❌
- Don't use technical jargon
- Don't make promises you can't keep
- Don't ignore messages
- Don't argue with users
- Don't share personal information
- Don't provide incorrect information
